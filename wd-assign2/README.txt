1. PROJECT DESCRIPTION
------------------------------------------------------------------------
CineWave is a responsive, cinematic web application built with semantic HTML5, modern external CSS3, and dynamic vanilla JavaScript. It offers users a seamless movie discovery and ticket booking experience inspired by premium streaming platforms. 

Key features include:
- A responsive dark-mode cinematic interface with glassmorphism and smooth transitions.
- A curated collection of 6 featured movies across various genres.
- An interactive ticket booking form with real-time cost calculation, payment method selection, and conditional credit card validation fields.
- A simulated SMS toast notification upon successful ticket booking.
- A rule-based movie recommendation engine matching user preferences.
- A user registration form and a dedicated movie watchlist management page.
